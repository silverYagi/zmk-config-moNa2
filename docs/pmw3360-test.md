# PMW3360トラックボール試験版

この版はPMW3360ドライバーを有効にしています。DYA StudioとKeyball39配列も維持します。
実機での動作は未確認です。本体内の配線は写真では追えないため、次の端子対応を仮定しています。

| 読取基板の信号 | XIAO側の設定 | 根拠 |
| --- | --- | --- |
| SCK | P0.05（出力） | moNa2標準設定を維持 |
| NCS | P0.09（出力） | moNa2標準設定を維持 |
| MOSI | P0.04（出力） | moNa2標準SDIOの端子を使用 |
| MISO | P0.02（入力） | 標準のMOTION端子が写真のMISO位置に対応すると仮定 |

写真の読取基板の端子表記は、SCK／NCS／GND／5V／GND／MOSI／MISOです。
7ピンが同じ順番で接続されているか、本体内部の導通・供給電圧は未確認です。
新しい出力GPIOは追加せず、標準設定の入力P0.02をSPIの入力へ変更しています。
MOTION割り込みは使わず4ms間隔で読み取ります。初期感度は500 CPIです。

## 試し方

1. DYA・キー入力を現在の確認版で確認した後、右側だけをUSBで接続します。
2. 右のリセットボタンを素早く2回押し、表示されたドライブへ
   `mona2-right-keyball39-dya-pmw3360-test.uf2`をコピーします。
3. 再起動から数秒待ち、USB接続のままボールを動かします。
4. カーソルの移動、クリック、Fnを押した状態でのスクロールを確認します。
5. DYA StudioへUSBで接続し、キーマップや入力プロセッサーの操作も確認します。

左側は先のDYA確認版と共通です。今回は設定リセットやペアリング消去をする必要はありません。
保存済みのDYA設定があれば引き継ぎます。特にスクロール対象レイヤーや感度の設定に注意してください。

## 動かない場合

この結果だけでセンサーの故障とは断定できません。供給電源、MISOの導通、接触、光学系を確認します。
配線を特定するためには、電源OFF・USBを外した状態で本体基板側の確認が必要です。
同じZIP内の`mona2-right-keyball39-dya-keyboard-only.uf2`を右へ上書きすれば、
センサー無効の確認版に戻せます。設定リセットは不要です。

センサーIDを正常に読めない場合は、ポーリングを開始しないようにしています。
DYAのPMW3610専用センサー診断・フレーム表示はPMW3360に対応しません。
診断に表示されるPMW3610用の結果で、この試験版の成否を判断しないでください。
