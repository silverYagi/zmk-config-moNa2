# Windows向けBluetoothパスキー認証版

PMW3360版に`CONFIG_ZMK_BLE_PASSKEY_ENTRY=y`だけを追加した比較版です。
既存の2M PHY無効化、PMW3360ドライバーと端子設定、DYA Studio、大西配列を維持します。
Windowsでのペアリング成功は実機確認が必要です。

元の`9874c0a`版では、ユーザーがボール移動・クリック・スクロール・DYA接続・大西レイヤーを確認済みです。
縦スクロール方向はDYAの`scroll`プロセッサーのY軸反転で修正済みです。
今回、センサーやスクロールの初期値は変更していません。
設定リセットはせず、保存済みのDYA設定を引き継いでください。

## 書き込み

1. DYAで変更を保存した後は10秒以上待ちます。
2. 右側をUSB接続し、リセットボタンを素早く2回押します。
3. 表示されたドライブへ`mona2-right-keyball39-dya-pmw3360-passkey.uf2`をコピーします。
4. 左右の電源をONにして、まずUSBでキーとボールが動くことを確認します。

左も同じDYA対応版を使用します。既に`mona2-left-keyball39-dya.uf2`を書き込み、右のUSB接続で左右とも入力できていれば、左の再書き込みは不要です。`settings_reset`は使用しません。

## Windowsとのペアリング

認証方式を変えたため、既存のホスト接続は再ペアリングが必要です。
まずはWindows用の接続先だけで試します。他のホストの登録を一括消去する必要はありません。

1. Windowsの「設定 → Bluetoothとデバイス」にmoNa2が残っていれば削除します。
2. DYAのBluetooth管理画面で空きプロファイルを選択します。
   登録済みのWindows用プロファイルを再利用する場合は、そのプロファイルだけをクリアします。
   選択・クリア後も10秒待ってからキーボードの電源を切ります。
3. DYAのUSB接続を切断してから、WindowsのBluetoothを一度OFF→ONにします。
4. 左右の電源をONにして、右のUSBケーブルを外します。
5. Windowsの「デバイスの追加 → Bluetooth」からmoNa2を選択します。
6. Windowsに表示された6桁の数字を、**moNa2自身で**入力し、最後にEnterを押します。
   普段使っている別のキーボードや、Windows側の入力欄には入力しません。

USB給電を続けて試す場合は、キーボードのBluetooth管理キー＋Wの位置で出力をBluetoothへ切り替えます。
通常のUSB出力へ戻す操作は管理キー＋Qの位置です。

## 数字の入力位置

今回の既定配列では、右親指の「数字・カーソル」レイヤーキー（`mo NUMBER_NAV`）を押したまま、左手で数字を入力します。
QWERTY・大西のどちらからでも同じ操作です。DYAで配列を変更している場合は、現在の数字キー割り当てを使用します。

左手の文字部分を上から見ると、数字は次の位置です。

```text
Esc   7   8   9   /
Tab   4   5   6   記号
  0   1   2   3   -
```

6桁を入力したらレイヤーキーを離し、右親指のEnterを押します。
入力を間違えた場合はEscで認証を中止し、Windowsから接続をやり直してください。

## 失敗した場合と切り戻し

- 6桁の番号が出る前に失敗するか、番号を入力した後に失敗するかを区別します。
- Windowsが接続済みと表示しても入力が出ない場合は、接続先プロファイルと出力先を確認します。
- 何度試しても失敗する場合は、表示文言と失敗のタイミングを記録します。
- 元に戻す場合は、右に`mona2-right-keyball39-dya-pmw3360-test.uf2`を上書きします。
  認証方式が変わるため、戻した後も接続するホストの再ペアリングが必要です。

PMW3610専用のDYA診断欄が利用不可になるのは、このPMW3360構成では想定どおりです。
