# DYA診断・ランタイム編集対応版

PMW3360とBLE再起動対策を維持し、添付の`mona2-2026-10-19.keymap`を既定配列にした左右セットです。
ZMKはcormoranの`main+dya`系、Zephyrは4.1系へ更新します。依存コミットは`dya-dependencies.json`に固定しています。

## 対応する機能

| DYAの画面 | 対応内容 |
| --- | --- |
| デバイス情報 | 右側のビルド、ハードウェア、ランタイム、Zephyrデバイス一覧 |
| 安定性 | 左右のフリーズ・クラッシュ・予期しないリセットの履歴。右経由で左も参照 |
| キースイッチ | 42キーの統計、チャタリング診断、左右中継とライブ押下表示 |
| スタック使用量 | 右側のスレッド別スタック最高水位 |
| マクロ＆コンボ | マクロ8枠・共有1024バイト、コンボ16枠をランタイム編集 |
| エンコーダー | レイヤーごとの回転割り当てをランタイム編集 |
| トラックボール | 動作確認済みのPMW3360ドライバーとランタイム入力処理を継続 |

PMW3610専用の表面診断は対応しません。実機のセンサーはPMW3360であり、PMW3610ドライバーを追加しても利用できません。
この欄の「利用できません」は残りますが、ポインタやスクロールの動作とは別です。
デバイス情報・ウォッチドッグ等の実機での表示と通信は、書き込み後に確認が必要です。

## 配列と初期設定

添付ファイルの6レイヤー×42キーの割り当てと表示名をそのまま保持します。
添付元は`config/keymaps/mona2-2026-10-19.keymap`に保存し、`config/moNa2.keymap`から読み込みます。
長押し修飾キーの既存設定は200ms・balancedです。
エンコーダーは初期状態で通常スクロール、MOUCE_FC（3）で音量です。DYAから変更できます。
ボールの自動マウス層はMOUCE_FC（3）、手動スクロール層はNAV_SC（4）へ合わせます。
以前DYAで直したスクロール方向は、保存設定がない場合の初期値にも反映します。

## 書き込み

1. 書き込み前にDYAで現在の配列とボール設定を保存・控え、10秒以上待ちます。
2. 左右それぞれのリセットを素早く2回押し、対応するUF2を書き込みます。
   - 左：`mona2-left-dya-features.uf2`
   - 右：`mona2-right-pmw3360-dya-features.uf2`
3. 左右の電源を一度OFF→ONにし、右のUSB接続で左右のキーとボールが動くことを確認します。
4. DYAをUSBで接続し、Studio Unlockを押して各機能を確認します。

今回は基盤と左右通信を更新するため、左右とも同じ版を使ってください。
設定リセットは最初から実行しません。保存済みDYA配列はファームウェアの既定値より優先されます。
添付配列と表示が異なる場合は、DYAのキーマップの初期値への復元で今回の既定配列に戻すか、DYAで配列を読み込んでください。
左右が繋がらなくなった場合は設定の移行状況を調べます。`settings_reset`は全設定を消すため、通常手順には含めません。

添付配列のStudio UnlockはBLE（5）の右手ホーム行いちばん右です。
BLE層は通常配列の左右の追加キー（位置26・27）から開けます。

## 注意と切り戻し

ウォッチドッグは診断履歴を保存する機能で、Windowsの初回Bluetoothペアリングを直す保証はありません。
フリーズが10秒続いた際は記録して再起動します。履歴は各半分16件で止まり、削除すると記録を再開します。
故障を意図的に起こすテスト機能、キー注入、イベントタップ、USBログ採取は有効にしません。
新機能を使うための基盤更新なので、ビルド成功だけでは実機動作の保証にはなりません。

切り戻す場合は、同梱の以前の`ble-fix212`版の左右UF2をそれぞれ書き込みます。
新版で保存した設定が旧版と互換かは、切り戻し後にも確認してください。
